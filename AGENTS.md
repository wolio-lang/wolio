# Wolio repository instructions

This repository currently contains design and preparation records. Read
`.blueprint/DOCUMENT_AUTHORITY.md`, `.blueprint/BASELINE-V1.md` and
`.execution/current-state.md` before acting on a project task.

Use `.blueprint/04-tasks/task-index.md` to locate each task's contract file and
`.blueprint/04-tasks/EXECUTION_CONTRACTS.md` for shared rules. Status lives only in `.execution/task-status.md`.
Do not implement code before owner baseline acceptance. A request to revise
documentation does not implicitly freeze it or start T001.

Follow the project specifications directly. Preserve user changes, do not invent semantics,
and record executed checks honestly. No automatic commit or push.
