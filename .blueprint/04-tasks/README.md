# Engineering Tasks

Each registered task has one standalone contract file `Tnnn-<slug>.md` naming its
authoritative specification, scope, out-of-scope owners, acceptance criteria,
verification and dependencies. Start at [task-index.md](task-index.md); shared
rules, ID allocation and change control are in
[EXECUTION_CONTRACTS.md](EXECUTION_CONTRACTS.md); new tasks use
[TASK_TEMPLATE.md](TASK_TEMPLATE.md). Task files never record status; live state
is only in `.execution/task-status.md`.
